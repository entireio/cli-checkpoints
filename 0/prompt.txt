### 4. PATCH `/{number}/threads/{threadId}` — update/resolve
Handler `:4968-5070`. Request schema `updateTrailThreadBodySchema` (`:1947-1953`):

Both optional; no required fields. `resolved` must be boolean if present (`:5010-5012`). `title` validated by `parseOptionalThreadTitle`.

Behavior split (`:5016-5061`):
