### Matter of taste

**8. `plugin_gitremote.go:83-107` — the pipe machinery.** It is close to minimal *for a pipe*, but the shape isn't forced. `exec.Cmd` spawns a copier goroutine for any non-`*os.File` `Stdout`, so a ~8-line writer that errors past the cap lets the whole block collapse to:

```go
cmd.Stdout, cmd.Stderr = &amp;stdout, &amp;stderr
if err := cmd.Run(); err != nil { ... }
```

Function body 25 lines → ~9; the 4-branch `switch`, the two identical `fmt.Errorf("git %s: %w", args[0], err)` returns at :90/:93, and the Start-before-Wait-after-ReadAll ordering constraint all disappear. Net LOC is roughly a wash once you count the writer type — call it even, better shape. (It also removes the case where an oversize response leaves `cmd.Wait()` blocked on a full pipe until the 2-minute timeout, but that's the correctness reviewer's territory.)

**9. `plugin_gitremote.go:110-119` — `stderrDetail` has exactly one caller.** It replaced `stderrSuffix`, which had six. Inlined at :105 it's 5 lines against a 10-line helper. Also `stderr.String()` beats `stderr.Bytes()` → `string(raw)`.
