Test mocks leak permanently into the process-global agent registry

Their binaries live in t.TempDir()s that are deleted at test end, so every later GetAgentsWithHooksInstalled call in package cli attempts to exec a deleted path.


This is benign today only because a missing binary makes are-hooks-installed report false. That is TempDir cleanup ordering doing the isolation work, not the test. TestRunAgentList_ShowsInstalledExternalByDefault registers a mock whose are-hooks-installed returns true — had that registration outlived its directory, it would have polluted the installed-agent set package-wide, and GetAgentsWithHooksInstalled feeds entire status, telemetry, and several other tests.


The full suite passes as-is, so this is hygiene rather than a live failure.


Suggested fix: add an agent.UnregisterForTesting (or a registry snapshot/restore helper) and wire it to t.Cleanup in both tests, so the registry returns to its prior state regardless of TempDir timing.
