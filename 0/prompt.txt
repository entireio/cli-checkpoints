Not the hook code — the controlling-terminal inheritance differs:

- macOS: child git (and its hook) commonly keeps the login shell's controlling terminal through the process group. Opening /dev/tty resolves to the real terminal. Hook works.
- Linux: with lazygit's pipe/session setup the child loses the controlling terminal. open("/dev/tty") with no controlling tty returns ENXIO / the read blocks forever. Hook fails or hangs.
