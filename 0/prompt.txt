1. P2 — Tracked local settings can be misidentified as the effective source
    cmd/entire/cli/doctor.go:1412-1424 reads settings.local.json directly and attributes the provider to it when values match.
    However, settings.Load ignores tracked local settings entirely. If both project and tracked-local files contain opencode, doctor
    recommends --local; that update remains ignored and the project-level fault persists. Check s.LocalLayerRejection() before
    considering the local file authoritative.

 2. P2 — New unit test reads the developer’s real repository settings
    cmd/entire/cli/doctor_summary_provider_test.go:44-46 invokes summaryProviderSourceLayer, which resolves the current repository and
    reads its actual .entire/settings.local.json. This violates repository isolation and makes output environment-dependent. Run this
    test in a testutil.InitRepo temporary repository or stub the source-layer seam.
