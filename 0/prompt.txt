## Important discrepancy up front
The task states the CLI passes `status`, `author`, `limit`, `offset`. The server's list route does **not** support those. The real query params are `pageSize` (default 50, clamped 1..100) and `pageToken` (opaque keyset cursor). There is **no** status/author filtering and **no** offset pagination on this endpoint — filtering is not implemented server-side at all; the list returns all of a repo's trails, `updated_at DESC` paginated by cursor.

## 4. Data source &amp; query
Table: **`repo_trails`** (Postgres, pgx pool). Store method `ListTrailsByRepo` — `internal/store/trails.go:67-122`:
```sql
SELECT id, number, title, status,
    COALESCE(branch, ''), COALESCE(original_branch, ''),
    base, type, COALESCE(priority, ''),
    author_account_id,
    assignees, reviewers, requested_reviewers,
    has_code_changes, comment_count, unresolved_count,
    created_at, updated_at, merged_at
FROM repo_trails
WHERE repo_id = $1 [AND (updated_at, id) &lt; ($n, $m)]
ORDER BY updated_at DESC, id DESC
LIMIT $k
```
- Sort: `updated_at DESC, id DESC` (id tiebreak for determinism).
- Filter: `repo_id` only, plus the optional keyset cursor predicate `(updated_at, id) &lt; (after.UpdatedAt, after.ID)`. No status/author filter.
- `id`/`author_account_id` are `ulid` bytea columns, bound as raw 16 bytes (`ulidBytes`) and surfaced as base32 text (`ulidText`).
- Fetches `limit+1` rows unmodified (httpapi layer trims + encodes the cursor).
- Related reads: `CountTrailsByStatus` (`trails.go:135`, stats endpoint, `GROUP BY status`) and `TrailsEnabled` (`trails.go:298`, product toggle, see §5).

## 5. Access control (the key part)
Two independent checks, both in the gate before the handler runs. Shared decision helper `trailsAccessAllowed` — `internal/httpapi/trails.go:67-77`:
```go
allowed, err := repoPermissionAllowed(ctx, deps, repoID, permission) // SpiceDB
if err != nil || !allowed { return allowed, err }
enabled, err := deps.Store.TrailsEnabled(ctx, repoID)               // product toggle
...
return enabled, nil
```

a) **Authorization (SpiceDB)** — `repoPermissionAllowed` (`internal/httpapi/authz.go:188-198`):
- Builds a per-request `AccessChecker` from the caller's verified Identity (`perRequestAccessChecker`, `perreq.go:18-24`).
- `ac.HasPermission(ctx, "repo", repoID, "pull")` — reads use `permRepoRead = "pull"` (`authz.go:32`); writes use `permRepoWrite = "push"`.
- `HasPermission` (`internal/auth/access.go:102-116`) calls `reader.Can(ctx, AccountSubject(identity.AccountID), action, Resource{repo, repoID})` against the **regional read-only SpiceDB** (`authz.Reader`, process-singleton gRPC client). The subject is **always** derived from the verified Identity, never from request input (confused-deputy guard, `access.go:88-92`). "pull" maps to `authz.Pull`. So **"the user has access to this repo's trails" = the caller's account holds the SpiceDB `pull` permission on `repo:&lt;repoID&gt;`** (direct grant, project membership, org cascade, or the `public_viewer` wildcard on public repos).
- Fail-closed: SpiceDB error → `503`; unknown type/permission → rejected.
- Note: this gate does **not** do `requireRepoAccess`'s repo-existence recheck (`authz.go:178-198` docstring) — existence is collapsed into the toggle result below.

b) **Product toggle** — `deps.Store.TrailsEnabled(ctx, repoID)` (`internal/store/trails.go:298-310`):
```sql
SELECT &lt;bool_or FILTER(...) COALESCE false for SettingTrails&gt;
FROM repo_setting_kv WHERE repo_id = $1
```
Trails must be enabled in repo settings KV.

c) **Collapsed 404 (existence-hiding)** — `trails.go:113-124`: unknown repo, denied (`pull` false), and trails-disabled **all** return the same `404 "repository not found"`. A caller can never distinguish them (spike parity, `trails.go:9-15`). Infra errors are mapped by `writeAccessErr` (`authz.go:217-224`) to their real status (500/503).

**For an account-scoped endpoint**, the relevant "across all repos" primitives already exist on `AccessChecker`:
- `AccessibleRepoSet()` (`access.go:126-157`) = SpiceDB `repo/pull` enumeration (the whole readable set, includes public_viewer wildcard), TTL-cached ~15s.
- `MemberRepoSet()` (`access.go:180-198`) = SpiceDB `repo/list` enumeration ("your repos": direct grants + project membership, **excludes** the public_viewer wildcard and platform cascade).
- The existing `/me/*` family (`internal/httpapi/me.go`, `experimental_me.go`) uses exactly this: `loadAccessibleSet` filters activity rows by `memberRepoSet` (membership), `loadReadable` filters by `accessibleRepoSet` (pull) — see `experimental_me.go:264-324` and `perreq.go:26-79`. The docstrings there spell out the membership-vs-pull choice (`experimental_me.go:284-297`).

## 7. Caller identity
- Middleware `requireAuth` — `internal/httpapi/router.go:471-492`: calls `deps.Authenticator.Authenticate(...)`; on success stashes the Identity via `auth.WithIdentity(ctx, id)` and the raw bearer via `auth.WithBearer`. Missing/invalid token → `401`. Also runs the waitlist/approval gate.
- `Authenticator.Authenticate` / `verifyBearer` — `internal/auth/auth.go:63-108`: validates a **bearer JWT** against Core JWKS. Contract (ADR 20260612): signature (EdDSA/RS256/ES256), required `exp`, audience pinned to this cell's jurisdiction host, `scope=openid`, optional exact `iss` match.
- Claims → Identity (`auth.go:29-35`, `101-107`):
  - `AccountID` = JWT `sub` (required; empty → error). This is the SpiceDB subject.
  - `Handle`, `Provider`, `ProviderUserID`, and **`HomeJurisdiction`** — the last comes from the `home_jurisdiction` claim carried on the identity token (entire-core #2094), read locally without calling Core.
- Extraction inside handlers/gates: `auth.FromContext(ctx)` (`auth.go:119-122`) returns `*Identity` or nil; helper `id(ctx)` (`experimental_me.go:257-262`) returns `AccountID`.
- **home_jurisdiction relevance**: identity tokens are per-jurisdiction and the audience is pinned to the cell's jurisdiction host, so a token is only accepted by its home cell. `/me/*` account-scoped reads run against the caller's home cell (where `my_activity` is consolidated); trails, by contrast, live in the one cell hosting the repo. An account-scoped `/me/trails` would be served by whichever cell the request lands on and would only see `repo_trails` rows for repos placed in that cell (no server-side cross-cell aggregation).

```go
func runTrailListAllWithClient(ctx context.Context, w io.Writer, client *api.Client, opts trailListOptions, statusFilters []trail.Status) error {
	authorFilter := opts.Author
	currentUserLogin := ""
	if authorFilter == trailListAuthorMe {
		login, err := fetchCurrentUserLogin(ctx, execRunner{})
		if err != nil {
			return err
		}
		currentUserLogin = login
		authorFilter = login
	}

	forge, owner, repo, err := resolveTrailRepoOrRemote(ctx, opts.Repo)
	if err != nil {
		return err
	}

	// Filtering, sorting (updated_at desc), and truncation all happen
	// server-side; the response carries the total match count so a capped
	// page never reads as the total number of matches.
	resp, err := client.Get(ctx, trailsBasePath(forge, owner, repo)+trailListQuery(statusFilters, authorFilter, opts.Limit))
	if err != nil {
		return fmt.Errorf("failed to list trails: %w", err)
	}
	defer resp.Body.Close()
	if err := checkTrailResponse(resp); err != nil {
		return err
	}

	var listResp api.TrailListResponse
	if err := api.DecodeJSON(resp, &amp;listResp); err != nil {
		return fmt.Errorf("failed to decode trail list: %w", err)
	}

	// Convert to metadata for display, attaching the browser URL (server-provided
	// when present, locally constructed as a fallback for older servers).
	trails := make([]*trail.Metadata, 0, len(listResp.Trails))
	for i := range listResp.Trails {
		m := listResp.Trails[i].ToMetadata()
		m.URL = trailDisplayURL(listResp.Trails[i], forge, owner, repo)
		trails = append(trails, m)
	}

	totalMatched := listResp.Total
	if totalMatched &lt; len(trails) {
		// Older servers don't report a total; fall back to the page size.
		totalMatched = len(trails)
	}

	if opts.JSON {
		enc := json.NewEncoder(w)
		enc.SetIndent("", "  ")
		if err := enc.Encode(trails); err != nil {
			return fmt.Errorf("failed to encode JSON: %w", err)
		}
		return nil
	}

	if len(trails) == 0 {
		printTrailListEmpty(w, authorFilter, statusFilters)
		return nil
	}

	printTrailList(w, trails, trailListDisplayOptions{
		RequestedAuthor: authorFilter,
		CurrentUser:     currentUserLogin,
		StatusFilters:   statusFilters,
		TotalMatched:    totalMatched,
	})

	if opts.Limit &gt; trailListServerMaxLimit &amp;&amp; totalMatched &gt; len(trails) {
		fmt.Fprintln(w)
		fmt.Fprintf(w, "Note: --limit %d exceeds the server maximum of %d trails per request.\n", opts.Limit, trailListServerMaxLimit)
	}

	return nil
}
```

```go
func printTrailListHeader(w io.Writer, opts trailListDisplayOptions, count int) {
	countStr := trailCountDisplay(count, opts.TotalMatched)
	// The noun refers to the full match set, so pluralize by the total when
	// the page is truncated ("1/2 trails", not "1/2 trail").
	nounCount := count
	if opts.TotalMatched &gt; count {
		nounCount = opts.TotalMatched
	}
```

```go
// resolveTrailBySelector resolves a trail by an optional selector (trail
// number, id, or branch). An empty selector falls back to the current branch's
// trail. It returns an actionable error (never a nil trail with a nil error)
// when nothing matches, so callers can rely on a non-nil result.
func resolveTrailBySelector(ctx context.Context, client *api.Client, forge, owner, repo, selector, branchOverride string) (*api.TrailResource, error) {
	selector = strings.TrimSpace(selector)
	if selector == "" {
		branch, err := resolveTrailBranch(ctx, branchOverride)
		if err != nil {
			return nil, fmt.Errorf("no trail selector given and current branch is unknown: %w\nhint: run 'entire trail list --status any' or pass a trail number, id, or branch", err)
		}
		found, err := findTrailByBranch(ctx, client, forge, owner, repo, branch)
		if err != nil {
			return nil, err
		}
		if found == nil {
			return nil, fmt.Errorf("no trail found for current branch %q\nhint: run 'entire trail create' or 'entire trail list --status any'", branch)
		}
		return found, nil
	}
	found, err := findTrailBySelector(ctx, client, forge, owner, repo, selector)
	if err != nil {
		return nil, err
	}
	if found == nil {
		return nil, fmt.Errorf("no trail %q found in %s/%s/%s (run 'entire trail list --status any')", selector, forge, owner, repo)
	}
	return found, nil
}
```

```go
func findTrail(ctx context.Context, client *api.Client, forge, owner, repo string, match func(api.TrailResource) bool) (*api.TrailResource, error) {
	// The list endpoint paginates; walk bounded pages so branch/number/id lookups do
	// not silently miss older trails beyond the first server-max page.
	offset := 0
	previousPageSignature := ""
	for range trailFindMaxPages {
		resp, err := client.Get(ctx, trailsBasePath(forge, owner, repo)+trailListQueryWithOffset(nil, "", trailListServerMaxLimit, offset))
		if err != nil {
			return nil, fmt.Errorf("list trails: %w", err)
		}

		var listResp api.TrailListResponse
		decodeErr := func() error {
			defer resp.Body.Close()
			if err := checkTrailResponse(resp); err != nil {
				return err
			}
			if err := api.DecodeJSON(resp, &amp;listResp); err != nil {
				return fmt.Errorf("decode trail list: %w", err)
			}
			return nil
		}()
		if decodeErr != nil {
			return nil, decodeErr
		}

		for i := range listResp.Trails {
			if match(listResp.Trails[i]) {
				return &amp;listResp.Trails[i], nil
			}
		}

		pageLen := len(listResp.Trails)
		if pageLen == 0 || pageLen &lt; trailListServerMaxLimit {
			break
		}
		if listResp.Total == 0 {
			pageSignature := trailListPageSignature(listResp.Trails)
			if pageSignature != "" &amp;&amp; pageSignature == previousPageSignature {
				break
			}
			previousPageSignature = pageSignature
		}
		offset += pageLen
		if listResp.Total &gt; 0 &amp;&amp; offset &gt;= listResp.Total {
			break
		}
	}
	return nil, nil //nolint:nilnil // nil, nil means "not found" — callers check both
}
```

```go
// resolveTrailRemote resolves the origin remote and ensures the forge is
// known to the trails API. Without this guard, an unmapped host (e.g.
// gitlab.com, or a misconfigured entire:// URL with no forge prefix)
// produces a malformed `/api/v1/trails//owner/repo` path that the server
// rejects with an opaque error instead of a clear "unsupported forge" one.
func resolveTrailRemote(ctx context.Context) (forge, owner, repo string, err error) {
	forge, owner, repo, err = gitremote.ResolveRemoteRepo(ctx, "origin")
	if err != nil {
		return "", "", "", fmt.Errorf("failed to resolve repository: %w", err)
	}
	if forge == "" {
		return "", "", "", errors.New("origin remote is not on a forge supported by Entire trails (supported: github.com)")
	}
	return forge, owner, repo, nil
}

// parseTrailRepoArg parses an explicit --repo value into the forge/owner/repo
// triple. It accepts the canonical "forge/owner/repo" form (e.g. gh/acme/app)
// as well as a full clone URL (https://, git@, or entire://) that gitremote
// can parse. A trailing ".git" on the repo is stripped.
func parseTrailRepoArg(raw string) (forge, owner, repo string, err error) {
	raw = strings.TrimSpace(raw)
	if raw == "" {
		return "", "", "", errors.New("empty --repo value")
	}
	// Bare path form: forge/owner/repo. URLs (with a scheme or an SCP "@")
	// fall through to the URL parser, which understands hosts and schemes.
	if !strings.Contains(raw, "://") &amp;&amp; !strings.Contains(raw, "@") {
		parts := strings.Split(strings.Trim(raw, "/"), "/")
		if len(parts) != 3 || parts[0] == "" || parts[1] == "" || parts[2] == "" {
			return "", "", "", fmt.Errorf("invalid --repo %q: expected forge/owner/repo (e.g. gh/acme/app) or a clone URL", raw)
		}
		// parts[0] must be a short forge id ("gh"), not a hostname. A host-like
		// value (github.com/acme/app) would otherwise be forwarded verbatim and
		// the server would reject the malformed path with an opaque error.
		if !gitremote.IsSupportedForge(parts[0]) {
			return "", "", "", fmt.Errorf("invalid --repo %q: %q is not a supported forge id (use a forge id like \"gh\", or pass a clone URL such as https://github.com/%s/%s)", raw, parts[0], parts[1], parts[2])
		}
		return parts[0], parts[1], strings.TrimSuffix(parts[2], ".git"), nil
	}
	info, perr := gitremote.ParseURL(raw)
	if perr != nil {
		return "", "", "", fmt.Errorf("invalid --repo %q: %w", raw, perr)
	}
	if info.Forge == "" {
		return "", "", "", fmt.Errorf("invalid --repo %q: unsupported forge host (supported: github.com)", raw)
	}
	return info.Forge, info.Owner, info.Repo, nil
}
```

```go
// TrailCursor is the keyset position for cursor pagination over
// ListTrailsByRepo's (updated_at DESC, id DESC) order — the last row of the
// previous page.
type TrailCursor struct {
	UpdatedAt time.Time
	ID        string
}

// ListTrailsByRepo pages a repo's trails, updated_at DESC (id DESC tiebreak
// for determinism). after nil selects the first page; a non-nil after adds
// the keyset predicate `(updated_at, id) &lt; (after.UpdatedAt, after.ID)`,
// matching the ORDER BY so the page picks up exactly where the previous one
// left off. The id side of the tuple compares on the raw 16-byte ULID
// (decoded via ulidBytes, same as every other ULID bind in this package) —
// not the base32 text — because the column itself is `ulid` (a bytea
// domain, see migrations/repo/001_init.sql): comparing bytea to bytea matches
// what the column actually stores and how the query planner evaluates it.
// This is safe: ULID's base32 (Crockford) text encoding is order-preserving
// over the raw bytes, so a bytea comparison and a text comparison agree on
// the same order.
//
// Returns up to limit+1 rows, unmodified — the caller detects and trims the
// extra row to decide whether a next page exists (mirrors ListRepoSessions'
// hasMore convention, but returns the raw slice since encoding the
// next-page cursor is the httpapi layer's job here).
func (s *RepoStore) ListTrailsByRepo(ctx context.Context, repoID string, limit int, after *TrailCursor) ([]TrailListRow, error) {
	if limit &lt;= 0 || limit &gt; 1000 {
		limit = 100
	}
	rid, err := ulidBytes(repoID)
	if err != nil {
		return nil, fmt.Errorf("store: list trails %s: %w", repoID, err)
	}
	conds := []string{"repo_id = $1"}
	args := []any{rid}
	if after != nil {
		aid, err := ulidBytes(after.ID)
		if err != nil {
			return nil, fmt.Errorf("store: list trails %s: cursor id: %w", repoID, err)
		}
		args = append(args, after.UpdatedAt, aid)
		conds = append(conds, fmt.Sprintf("(updated_at, id) &lt; ($%d, $%d)", len(args)-1, len(args)))
	}
	args = append(args, limit+1)
	q := `
		SELECT id, number, title, status,
			COALESCE(branch, ''), COALESCE(original_branch, ''),
			base, type, COALESCE(priority, ''),
			author_account_id,
			assignees, reviewers, requested_reviewers,
			has_code_changes, comment_count, unresolved_count,
			created_at, updated_at, merged_at
		FROM repo_trails
		WHERE ` + strings.Join(conds, " AND ") + `
		ORDER BY updated_at DESC, id DESC
		LIMIT $` + strconv.Itoa(len(args))
	rows, err := s.pool.Query(ctx, q, args...)
	if err != nil {
		return nil, fmt.Errorf("store: list trails %s: select: %w", repoID, err)
	}
	out, err := pgx.CollectRows(rows, func(r pgx.CollectableRow) (TrailListRow, error) {
		var (
			tr         TrailListRow
			id, author []byte
		)
		if err := r.Scan(&amp;id, &amp;tr.Number, &amp;tr.Title, &amp;tr.Status,
			&amp;tr.Branch, &amp;tr.OriginalBranch, &amp;tr.Base, &amp;tr.Type, &amp;tr.Priority,
			&amp;author, &amp;tr.Assignees, &amp;tr.Reviewers, &amp;tr.RequestedReviewers,
			&amp;tr.HasCodeChanges, &amp;tr.CommentCount, &amp;tr.UnresolvedCount,
			&amp;tr.CreatedAt, &amp;tr.UpdatedAt, &amp;tr.MergedAt); err != nil {
			return tr, fmt.Errorf("scan trail: %w", err)
		}
		tr.ID = ulidText(id)
		tr.AuthorAccountID = ulidText(author)
		return tr, nil
	})
	if err != nil {
		return nil, fmt.Errorf("store: list trails %s: scan: %w", repoID, err)
	}
	return out, nil
}
```

## 2. `TrailListRow` + ulid helpers

```go
// ulidBytes decodes a 26-char Crockford base32 ULID to its 16 raw bytes for a
// bytea bind. The empty string maps to a nil bind — a NULL ulid column (e.g. an
// unresolved owning_project_id / pusher_account_id).
func ulidBytes(s string) ([]byte, error) {
	if s == "" {
		return nil, nil
	}
	u, err := ulid.Parse(s)
	if err != nil {
		return nil, fmt.Errorf("store: invalid ULID %q: %w", s, err)
	}
	b := make([]byte, len(u))
	copy(b, u[:])
	return b, nil
}

// ulidText encodes 16 raw ULID bytes to the canonical 26-char base32. nil/empty
// (a NULL column) maps to "".
func ulidText(b []byte) string {
	if len(b) == 0 {
		return ""
	}
	var u ulid.ULID
	copy(u[:], b)
	return u.String()
}
```

```go
// ulidBytesList decodes a slice of ULID strings for an `= ANY($n)` bytea[] bind.
func ulidBytesList(ss []string) ([][]byte, error) {
	out := make([][]byte, len(ss))
	for i, s := range ss {
		b, err := ulidBytes(s)
		if err != nil {
			return nil, err
		}
		out[i] = b
	}
	return out, nil
}
```

```go
func (s *RepoStore) OpenPullRequestsForRepos(ctx context.Context, ids []string) ([]PullRequestListRow, error) {
	if len(ids) == 0 {
		return nil, nil
	}
	idB, err := ulidBytesList(ids)
	if err != nil {
		return nil, fmt.Errorf("store: open prs: %w", err)
	}
	// A set that fits one bind runs as a single query, keeping its SQL ordering
	// (updated_at desc, number desc) verbatim. A thousands-repo caller would
	// otherwise bind one giant array against github_pull_request_meta, so its set
	// is split across chunked binds and the union re-sorted on the same keys to
	// keep the outward ordering unchanged.
	if len(idB) &lt;= idBindChunk {
		return s.openPullRequestsChunk(ctx, idB)
	}
	var out []PullRequestListRow
	for chunk := range slices.Chunk(idB, idBindChunk) {
		chunkRows, err := s.openPullRequestsChunk(ctx, chunk)
		if err != nil {
			return nil, err
		}
		out = append(out, chunkRows...)
	}
	sort.Slice(out, func(i, j int) bool {
		if !out[i].UpdatedAt.Equal(out[j].UpdatedAt) {
			return out[i].UpdatedAt.After(out[j].UpdatedAt)
		}
		return out[i].Number &gt; out[j].Number
	})
	return out, nil
}
```

### Notable gotchas for the plan (evidence-based, not design)
- `memberRepoSet` returns `map[string]struct{}` (repo-id ULID strings), not bytes — the ULID→bytea decode happens inside the store via `ulidBytesList`, exactly as `OpenPullRequestsForRepos` does. Your `TrailsForRepos` should take `[]string` and decode internally.
- `ListTrailsByRepo` binds `repo_id = $1` (single repo). For the account-scoped read you need a new store method with `repo_id = ANY($n)` — model it on `openPullRequestsChunk` (`= ANY($1)` over `[][]byte`), including the `idBindChunk` split if you expect large member sets.
