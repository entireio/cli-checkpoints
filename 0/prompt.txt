## Summary

`entire checkpoint list` and `entire session list` read from two entirely separate stores. Checkpoints live in **git refs** (the `entire/checkpoints/v1` branch, per-checkpoint `refs/entire/checkpoints/...` refs, and ephemeral shadow branches `entire/&lt;hash&gt;`); sessions are listed only from the local filesystem state files in `.git/entire-sessions/`. Nothing keeps them in sync, so several code paths legitimately produce checkpoints with no listable session.

a. **Ended sessions still list** — `session list` does not hide ended sessions; `sessionPhaseLabel` returns `"ended"` when `EndedAt != nil` (`sessions.go:313-322`). So merely stopping/condensing a session does not by itself make it disappear.

b. **Session state is auto-deleted after 7 days; checkpoints are not.** On every load/list, stale state files are removed:

```go

`IsStale` returns true when the last interaction (or start) is older than `StaleSessionThreshold = 7 * 24 * time.Hour` (`state.go:475-483`, constant at `state.go:29-31`). `StateStore.List` skips such entries (`state.go:701-703`, "Not found or stale (Load handles cleanup)").

Meanwhile the checkpoints those sessions produced were condensed to the permanent `entire/checkpoints/v1` branch on user commits (CLAUDE.md:575) and persist in git indefinitely. So a session that ran, was committed, then went untouched for 7+ days has its `.git/entire-sessions/&lt;id&gt;.json` purged, yet its checkpoints remain listable.

Related cleanup asymmetry worth noting: CLAUDE.md:584 documents the reverse pruning only — an **orphaned shadow branch** (ephemeral) without a session-state file is reset on next session start. That governs ephemeral shadow branches, not committed `v1`/refs checkpoints, which are never pruned by session lifecycle. `entire clean` (`clean.go:26-30`) can delete session state files as an explicit user action too.

## 1. `agentimport.Run` flow and the per-session/per-turn loop structure

File: `/Users/ninawork/entire/devenv/cli/cmd/entire/cli/agentimport/agentimport.go`

The full `Run` function (lines 111-171). The critical structure is the **outer loop over sessions** (`for _, sf := range files`, line 129) containing the **inner loop over turns** (`for _, turn := range turns`, line 145). The point where "all turns for one session are done" is at the **end of the outer loop body, after line 168** (the inner loop closes at 168; the session iteration closes at 169). That is where a per-session `session.State` write would be inserted.

```go
func Run(ctx context.Context, repo *git.Repository, imp Importer, opts Options) (Result, error) {
	var res Result
	files, err := imp.Discover(opts.RepoRoot, opts.OverridePath, opts.Now, opts.SessionFilter)
	if err != nil {
		return res, fmt.Errorf("discover %s sessions: %w", imp.Name(), err)
	}

	stores, err := cp.Open(ctx, repo, cp.OpenOptions{})
	if err != nil {
		return res, fmt.Errorf("open checkpoint store: %w", err)
	}
	existing := make(map[string]bool)
	if infos, listErr := stores.Persistent.List(ctx); listErr == nil {
		for _, in := range infos {
			existing[in.CheckpointID.String()] = true
		}
	}

	for _, sf := range files {
		res.SessionsScanned++
		full, readErr := os.ReadFile(sf.Path)
		if readErr != nil {
			return res, fmt.Errorf("read %s: %w", sf.Path, readErr)
		}
		turns, splitErr := imp.SplitTurns(sf, full)
		if splitErr != nil {
			return res, fmt.Errorf("split %s session %s: %w", imp.Name(), sf.SessionID, splitErr)
		}
		// Redact the session transcript once and reuse it for every turn's
		// checkpoint (each turn stores the full session transcript with its own
		// CheckpointTranscriptStart). Redacting per turn would be O(turns).
		// Computed lazily so a fully-skipped or dry-run file pays nothing.
		var red redact.RedactedBytes
		redacted := false
		for _, turn := range turns {
			cid := DeriveCheckpointID(sf.SessionID, turn.UUID)
			if existing[cid.String()] {
				res.TurnsSkipped++
				continue
			}
			if opts.DryRun {
				res.TurnsImported++ // counts what would import
				continue
			}
			if !redacted {
				r, rerr := redact.JSONLBytes(full)
				if rerr != nil {
					return res, fmt.Errorf("redact %s transcript: %w", sf.SessionID, rerr)
				}
				red = r
				redacted = true
			}
			if err := writeTurn(ctx, stores, imp, cid, sf, red, turn); err != nil {
				return res, err
			}
			existing[cid.String()] = true
			res.TurnsImported++
		}
	}
	return res, nil
}
```

Note: `writeTurn` (lines 173-191) writes the read-only checkpoint via `stores.Persistent.Write(ctx, cp.Session(cp.WriteOptions{...}))`. There is no session-state write anywhere in this file today.

Important gap for planning: within the session loop there is **no accumulator** of per-session data (e.g. earliest/latest turn time, total tokens). Each turn's data is consumed immediately in the inner loop. A per-session state write would need to aggregate across `turns` (e.g. min/max `turn.CreatedAt`, sum tokens) inside or after the inner loop.

```go
func Run(ctx context.Context, repo *git.Repository, imp Importer, opts Options) (Result, error) {
	var res Result
	files, err := imp.Discover(opts.RepoRoot, opts.OverridePath, opts.Now, opts.SessionFilter)
	if err != nil {
		return res, fmt.Errorf("discover %s sessions: %w", imp.Name(), err)
	}

	stores, err := cp.Open(ctx, repo, cp.OpenOptions{})
	if err != nil {
		return res, fmt.Errorf("open checkpoint store: %w", err)
	}
	existing := make(map[string]bool)
	if infos, listErr := stores.Persistent.List(ctx); listErr == nil {
		for _, in := range infos {
			existing[in.CheckpointID.String()] = true
		}
	}

	for _, sf := range files {
		res.SessionsScanned++
		full, readErr := os.ReadFile(sf.Path)
		if readErr != nil {
			return res, fmt.Errorf("read %s: %w", sf.Path, readErr)
		}
		turns, splitErr := imp.SplitTurns(sf, full)
		if splitErr != nil {
			return res, fmt.Errorf("split %s session %s: %w", imp.Name(), sf.SessionID, splitErr)
		}
		// Redact the session transcript once and reuse it for every turn's
		// checkpoint (each turn stores the full session transcript with its own
		// CheckpointTranscriptStart). Redacting per turn would be O(turns).
		// Computed lazily so a fully-skipped or dry-run file pays nothing.
		var red redact.RedactedBytes
		redacted := false
		for _, turn := range turns {
			cid := DeriveCheckpointID(sf.SessionID, turn.UUID)
			if existing[cid.String()] {
				res.TurnsSkipped++
				continue
			}
			if opts.DryRun {
				res.TurnsImported++ // counts what would import
				continue
			}
			if !redacted {
				r, rerr := redact.JSONLBytes(full)
				if rerr != nil {
					return res, fmt.Errorf("redact %s transcript: %w", sf.SessionID, rerr)
				}
				red = r
				redacted = true
			}
			if err := writeTurn(ctx, stores, imp, cid, sf, red, turn); err != nil {
				return res, err
			}
			existing[cid.String()] = true
			res.TurnsImported++
		}
	}
	return res, nil
}
```
