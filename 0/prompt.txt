Injection lost to side LLM calls
Medium Severity

pendingInjection is applied on the next experimental.chat.system.transform call and then cleared. That hook also runs for non-main LLM work such as session title generation, so a side call can consume the one-shot Entire trail context and leave the coding agent without it for the rest of the session.
