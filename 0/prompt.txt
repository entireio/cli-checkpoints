`dupl`'s test/prod split is `strings.HasSuffix(fn, "_test.go")` only — it never calls anything equivalent to `cfg.For(fn).Ranked`. `generated:coreapi` (`internal/coreapi/*_gen.go`, non-test) and `test-infra` (`testutil.go`, `benchutil.go`, non-test helper files — confirmed both exist and are non-`_test.go`) are both `norank`, but any dupl finding in them lands in `prod_by_feature`/`lines_by_feature`/`cross`, which `render.py`'s `dupl_rows()` (line 204) displays without re-filtering. So generated-client boilerplate or test-helper duplication can appear ranked alongside genuine hand-written duplication in the page's "Duplication" section, under features the rest of the pipeline has already agreed to exclude from rankings.

**Cost**: skews exactly the kind of "where's the real duplication problem" conclusion this sub-tool exists to answer, and it's inconsistent with `main.go`/`reach/main.go`, which both preserve the `Ranked` flag through to their own JSON for downstream use.

**Deeper fix**: bucket via `cfg.For(fn).Ranked` (fold norank into the same excluded bucket as test, or track it separately) instead of the suffix check alone.

**Worth doing**: yes, moderate priority — two-line fix, one report column affected.

### 4. `main.go` compares against the bare string `"_unmapped"` instead of an exported sentinel from `cx`

`file: tools/complexity/main.go`, `line: 298`

**Cost**: low today (one call site, well-commented), but it's the one place outside `internal/cx` "which decides `_unmapped`" leaks out; a future rename of the sentinel in `cx.go` compiles fine and silently breaks unmapped-file reporting.

**Deeper fix**: export `cx.Unmapped` (or add `Feature.IsUnmapped() bool` / a `Config` helper) so `main.go` never needs the literal.

**Worth doing**: optional — cheap, mostly hygiene, no live bug today.

### 5. `render.py`'s coverage-chip cutoffs (50/65) are independent literals, not derived from `COV_WARN`

`file: tools/complexity/render.py`, `line: 147-148` (`cov_cell`), `line: 339` ("Coverage under 65% is flagged")

**Worth doing**: optional — one-line fix, only manifests if the flag is ever changed from default.
