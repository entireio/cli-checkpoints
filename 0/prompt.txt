## 6. Help/completion customization

- **Help command is customized**: `NewHelpCmd(rootCmd)` in `help.go:11`, installed via `SetHelpCommand` (root.go:147). It adds a hidden `-t/--tree` flag but delegates to `targetCmd.Help()` for normal help — it does not override help templates, so grouped rendering of `entire --help`/`entire help` is unaffected. Its tree walker `getVisibleCommands` (help.go:73) skips `Hidden` and `help` (not group-aware, but purely cosmetic for the `-t` tree).
- Because a **custom help command** is set and the **completion command is hidden** (`HiddenDefaultCmd: true`, root.go:44-46), neither appears in the "Available Commands" list. Cobra normally auto-assigns `help` and `completion` to their own ungrouped section; with groups enabled, if you want them tucked under a group you would call `SetHelpCommandGroupID` / `SetCompletionCommandGroupID`. Since completion is hidden and help is custom (and typically left ungrouped/"Additional Commands"), these are optional — but note the help command is created in `NewHelpCmd` and added via `SetHelpCommand`, so any `GroupID` on it must be set on the returned command or via `rootCmd.SetHelpCommandGroupID(...)` after `SetHelpCommand`.
