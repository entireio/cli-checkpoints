Both pass locally at -count=20, so it only shows under CI's timing.

THE ROOT CAUSE (confirmed, not a guess)
`closedServerURL()` at internal/remotehelper/transport/proxy_test.go:869:

    func closedServerURL() string {
        s := httptest.NewServer(http.HandlerFunc(func(http.ResponseWriter, *http.Request) {}))
        url := s.URL
        s.Close()
        return url
    }

It manufactures a "guaranteed dead" node URL by starting a server and closing
it. Closing returns the port to the OS. Every test in that file is
t.Parallel(), so while one test is still using that URL as a dead node,
another test's httptest.NewServer can be handed the SAME port by the OS.

That is one event producing both failures:
- TestColdPathRedirectAllReplicasFail (path "/et/alice/repo") expects both dead
  replicas to fail so the proxy reports "all 2 nodes failed". One "dead" node
  was alive and answered 200, so require.Error got nil.
- TestServiceRPC owned the server that inherited the port, so the other test's
  request landed in its handler — which is exactly why it logged the foreign
  path /et/alice/repo/info/refs and method GET.

Neither test is wrong on its own. The helper hands out an address it does not
own. 12 call sites use it in that file, so this will keep firing.

THE FIX
Own the port for the test's lifetime instead of releasing it. Replace the
helper with one that keeps a listener bound and fails every connection:

    func deadServerURL(t *testing.T) string {
        t.Helper()
        l, err := net.Listen("tcp", "127.0.0.1:0")
        require.NoError(t, err)
        t.Cleanup(func() { _ = l.Close() })
        go func() {
            for {
                c, err := l.Accept()
                if err != nil {
                    return
                }
                _ = c.Close() // dial connects, request never completes
            }
        }()
        return "http://" + l.Addr().String()
    }

Nothing else can bind the port because it stays held. Requests still fail, so
the existing assertions hold: "all 2 nodes failed" and "after entry-domain
redirect" come from the proxy's own aggregation, not from the dial error text.
It now needs a *testing.T, so update all 12 call sites to pass t.

Simpler alternative if you prefer a one-liner: return "http://127.0.0.1:0".
Connecting to port 0 fails immediately and nothing can ever bind it. Race-free,
but less faithful to "a node that went away" — your call which reads better.
