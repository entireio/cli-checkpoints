- `MemoryObject.Write` is `o.cont = append(o.cont, p...)` (`plumbing/memory.go:74`) → one 65MB alloc + memcpy.
- `ObjectStorage.SetEncodedObject` (`storage/filesystem/object.go:489`) has **no** pre-existence check: it opens a temp objfile writer and `CopyBufferPool`s the payload through `objfile.Writer`, which zlib-deflates while hashing (`plumbing/format/objfile/writer.go:82`), then returns `o.Hash()`, which hashes `o.cont` a **second** time (`plumbing/memory.go:28`).
