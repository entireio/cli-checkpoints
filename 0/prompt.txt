PATH conflict detection compares existing binaries against $installPath before the file exists. Get-NormalizedPath in Test-SamePath will fail on the non-existent path (caught at line 238), returning false for every comparison. This incorrectly blocks reinstallation to the same directory with "PATH needs adjustment" error, even though it's the intended upgrade path. The check at line 353 Test-SamePath -Left $first.Source -Right $installPath needs to handle the case where $installPath doesn't exist yet (e.g., normalize and compare parent directory + filename separately, or defer conflict detection until after the copy).
