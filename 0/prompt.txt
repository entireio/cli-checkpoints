# Harden executable resolution across the CLI

Strengthen the guarantees around how the CLI decides which binaries to run, so
that "we only execute binaries from trusted, absolute locations" is enforced in
one place rather than restated per call site.

## 1. Make the absolute-PATH rule shared and unconditional

`findInaccessiblePlugin` (`cmd/entire/cli/plugin.go`) already drops non-absolute
`$PATH` entries. Extract that rule into a single helper — e.g. `pathScanDirs()`
returning only absolute entries — and route every `$PATH` scanner through it.

Apply it to the external-agent scanner in
`cmd/entire/cli/agent/external/discovery.go`, which currently globs each `$PATH`
entry verbatim and executes what it finds. Because it resolves by glob rather
than `exec.LookPath`, it gets none of Go's `ErrDot` protection, and the paths it
produces contain separators, so `exec.Command`'s re-check does not apply either.
Two scanners carrying the same rule independently is how they drifted; one
helper keeps them aligned.

## 2. Require absolute paths at the point of execution

In `external.Agent.run` (`cmd/entire/cli/agent/external/external.go`), assert
that `binaryPath` is absolute before spawning. `run` sets `cmd.Dir = repoRoot`,
and `os/exec` resolves a relative `Path` against `Dir` — so the file that
`registerExternalAgent` stats and validates is not necessarily the file that
executes. Anchoring on an absolute path makes validation and execution refer t
the same file, and gives `New` (exported) its own guarantee independent of the
scanner.

## 3. Extend the existing settings-trust model to `external_agents`

`external_agents` enables PATH scanning and execution, but is honored from the
version-controlled `.entire/settings.json`. Bring it under the same trust gate
as `redaction.openai_privacy_filter.command`
(`settings/opf_command_trust.go`): honor it only from a verified-untracked
`.entire/settings.local.json`, downgrade rather than error, and surface the
rejection reason. The rationale in `enforceOPFCommandTrust` — a JSON settings
diff does not read as executable to a reviewer — applies unchanged.

While there, audit the six `DiscoverAndRegisterAlways` call sites in `setup.go
and confirm each genuinely needs to bypass the setting.

## 4. Validate all plugin-dir overrides consistently

`pluginParentDir` (`cmd/entire/cli/plugin_store.go`) rejects a relative
`ENTIRE_PLUGIN_DIR` with a clear rationale, but `XDG_DATA_HOME` and
`LOCALAPPDATA` are joined unchecked. Downstream layers (`osroot`, and `main.go`
restoring `PATH`) currently catch this, so the change is about stating the
invariant where it is defined rather than relying on two distant backstops.
Reject any non-absolute parent dir at the source, with the same error shape.

## Regression coverage

For each of the above, assert the *behavior* rather than the error: a planted
binary reachable only via a relative `$PATH` entry must not execute, and a
relative `binaryPath` must be refused before spawn.
