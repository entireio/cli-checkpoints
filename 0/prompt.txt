
Setting `opts.Yes = true` here (to auto-answer choices already covered by the onboarding form) also silently short-circuits the telemetry consent prompt in `runEnableInteractive` (`setup.go`'s `if opts.Yes { ... } else if err := promptTelemetryConsent(...)`), which is not gated by the new `SuppressAdditionalSetup` flag the way the Vercel/history-import prompts are. As a result, every first-time bare `entire configure` run opts the user into telemetry (`settings.Telemetry = true`) without ever asking, even though this flow is explicitly framed as interactive onboarding. Consider passing telemetry consent through the onboarding form (or excluding it from the `Yes` auto-answer) so the same care given to Vercel/history import applies to telemetry.
