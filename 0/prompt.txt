Agent.run indexes args[0] without guarding against an empty args slice. Since run is variadic and exported methods could call it with no args, this can panic before returning a useful error; add an explicit len(args)==0 check first.

updateSummaryGenerationSettings writes external_agents through enableExternalAgentsLocally, then may save the in-memory struct back to the same local file. That struct still has ExternalAgents false, and omitempty drops the key, so the grant just written is overwritten. entire configure --local --summarize-provider for an external agent, or the same command in a local-only repo, prints the auto-enabled notice even though the next load will not honor the setting.
