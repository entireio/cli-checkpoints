## Official Documentation Answer

**1. Timeout Setting in settings.json:**
Yes, the `timeout` field is configurable for hooks. According to the [hooks reference](https://code.claude.com/docs/en/hooks.md):

```json
{
  "hooks": {
    "SessionEnd": [
      {
        "hooks": [
          {
            "type": "command",
            "command": "/path/to/cleanup.sh",
            "timeout": 30  // Configurable in seconds
          }
        ]
      }
    ]
  }
}
```

The **default timeout is 600 seconds (10 minutes)** for command, HTTP, and MCP tool hooks.

**2. Grace Period on Process Exit:**
The official documentation does **not mention a grace period** or special handling for SessionEnd hooks during process exit. However, this is a significant gap because:

- The docs state a 600s default, but you're observing ~1.5s cancellation
- The docs don't address whether Claude Code actually respects the full timeout when the process is exiting

**3. Configurability:**
You should be able to set `timeout` in settings.json to increase the timeout, but the documentation doesn't clarify whether process-exit grace periods override this setting.
