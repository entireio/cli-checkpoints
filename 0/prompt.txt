6. `testutil.WaitForCheckpoint(t, s, 30*time.Second)` + `AssertCheckpointAdvanced`.
7. `AssertHasCheckpointTrailer(HEAD)` → `cpID1`, `AssertCheckpointExists(cpID1)`; same for `HEAD~1` → `cpID2`.
8. `CheckpointIDs` → each `AssertCheckpointHasSingleSession`, plus `AssertDistinctSessions`.
9. `WaitForNoShadowBranches(10s)`.

**Cheaper/faster alternatives** if you want the truly minimal smoke:
- `TestSingleSessionManualCommit` (`e2e/tests/single_session_test.go:42`) — 1 prompt, 1 manual commit, checkpoint + metadata assertions. Fastest full-loop validation.
- `TestMultiSessionManualCommit` (`multi_session_test.go:15`) — 2 prompts, 1 user commit, 1 checkpoint. Matches "2 prompts" but only one commit/checkpoint.

## 5. Binary: built from source, but overridable

- `e2e/entire/entire.go:16` — `BinPath()` reads **`E2E_ENTIRE_BIN`** and `log.Fatal`s if unset ("run tests via `mise run test:e2e`"). There is no PATH lookup fallback and no use of a system-installed `entire`.
- `mise-tasks/test/e2e/_default` sets it: **only if `E2E_ENTIRE_BIN` is already set does it skip `mise run build`.** So `E2E_ENTIRE_BIN=/path/to/entire mise run test:e2e ...` points the suite at a pre-installed binary and skips the build entirely. (The `canary` and `roger-roger` tasks always build and overwrite it.)
- `main_test.go` then (a) `ensureHookEntireBinary()` — creates a symlink (Unix) or file copy (Windows) named `entire`/`entire.exe` next to the resolved binary if the name differs, so hooks invoking bare `entire` hit the same build; (b) prepends that directory to `PATH`.
- Preflight in `TestMain` `os.Exit(1)`s if `git` (and `tmux` on non-Windows) or any registered agent's `Binary()` is missing from PATH.

## 6. Windows support

Yes — Windows is a first-class CI leg, not skipped.

- `.github/workflows/e2e-windows.yml` runs the **full suite** on `windows-latest` with `--agent claude-code`, and is invoked from `e2e.yml` via `uses: ./.github/workflows/e2e-windows.yml`. A Windows failure is classified RED (real regression) in the Slack notifier.
- `runtime.GOOS` usages in `e2e/`:
  - `e2e/tests/main_test.go:74` — `tmux` is only a required preflight binary on non-Windows.
  - `e2e/tests/main_test.go:117,127` — `ensureHookEntireBinary` uses `entire.exe` and file-copies instead of symlinking.
  - `e2e/agents/claude.go:142` — `StartSession` returns `nil, nil` on Windows ("not supported" per the `Agent` interface contract).
- There are **no `t.Skip` calls keyed on `runtime.GOOS`** in `e2e/tests/`. Affected tests: `TestInteractiveMultiStep`, the three `TestInteractive*` attribution tests, `TestInteractiveContentOverlapRevertNewFile`, and the two `TestFactory*` hook tests.
