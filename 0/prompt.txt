But `CapturePrePromptState` (TurnStart) and `CapturePreTaskState` (SubagentStart) **failed the hook** on status error — both now fail open and record an `UntrackedScanSkipped` marker so the paired end-hook skips new-file detection (without a baseline, every untracked file would be misattributed to the agent).
- **Zombie prevention**: process-local latch (`statusBudgetBreached`) — after one breach, every later `StatusWithBudget` in the same hook process fails fast. This matters because the turn-start hook walks twice (pre-prompt capture + prompt attribution). Note: this branch's CLAUDE.md documents that the status cache was removed, so there was no `WithStatusCache` contract to preserve.

## Budget chosen

**20s** (`statusWalkBudget` const with full rationale comment): far beyond any healthy repo's walk while leaving ~40s of the agent's ~60s hook timeout for the rest of the capture path.
