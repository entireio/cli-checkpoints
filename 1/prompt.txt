**Concrete cost (measured on this machine, darwin/arm64 M4 Max):**

| what | measured |
|---|---|
| `entire status` end-to-end, 0–20 sessions | **40–44 ms** (`BenchmarkStatusCommand`) |

The candidate set is the part the diff changes, and it changes it a lot in exactly the direction that matters: a session is `ACTIVE` only between TurnStart and TurnEnd, so the old gate only caught agents killed *mid-turn*. `IDLE` is the resting state — every agent quit at the prompt. **Cheaper alternative** — the machinery is already in this diff and deliberately declined:

1. Pass a real deadline instead of `time.Time{}`. `endSessionNow` now takes `condenseDeadline` precisely for this; the sweep opts out with the comment "not inside an agent's bounded shutdown". 2. Better: split the work by caller. 3. At minimum, cap the number of condenses per `status` invocation (1–2) so the backlog drains across invocations instead of in one stall.
