# Vulnerability classes (adversarial, in priority order)

1. ACE/RCE from repo or remote content (highest). Any path where repo files, `.entire` settings, checkpoint data, branch names, or server responses cause code to run: a binary resolved from anything but the trusted installed `entire` (no `go run`, `scripts/`, repo-relative, or `.entire`-supplied command/interpreter); settings that re-introduce a `local_dev`-style escape; attacker strings reaching `exec.Command` argv/env (PATH, `LD_PRELOAD`/`DYLD_*`, git `core.hooksPath`/`fsmonitor`/alias/`ext::`, `GIT_*`); weakened stale-hook detection or hook forms beyond the hardcoded allowlist.
2. Path traversal / arbitrary read or write (CWE-22/59). Server- or repo-supplied names joined into paths without traversal validation (`../`, absolute, Windows drive/UNC); zip-slip extraction; symlink/TOCTOU on write into the worktree or `.entire/`; any restore/resume/rewind write not confined by a descend-only primitive. A regression of the GHSA-2h46 fix is critical.
3. Data/credential exfiltration. Tokens or secrets in logs, errors, stdout, or pushed transcript/commit content; redaction/OPF weakened (patterns removed, redaction skipped on a path, egress set widened); egress destination (push remote, core URL, cluster endpoints) redirected via repo settings, config, or server response.
4. SSRF / transport tampering. Attacker-controlled core/cluster URLs or replica lists reaching HTTP requests; `.well-known` discovery trusting arbitrary hosts; TLS weakened (`ENTIRE_TLS_SKIP_VERIFY`, lowered `MinVersion`); token `aud`-claim validation loosened; `--insecure-http-auth` reachable by default.
5. Supply chain. New or changed deps, `replace` to untrusted forks, loosened pins, alternate proxies, build- or run-time fetches.
6. CI/CD tampering. Workflows or mise tasks that download/execute external code, unpin actions, widen token/OIDC scope, or leak secrets.
7. Access control. Auth/grant/core-resolution changes that skip validation, widen org/repo scope, or expose privileged endpoints.
8. Untrusted deserialization / resource exhaustion. Removed `DisallowUnknownFields`, unbounded reads or decompression (transcript/image bombs), missing size/depth limits, or panics parsing hostile metadata, settings, or responses.

Weight findings by whether untrusted input actually reaches the sink: a boundary merely touched is Moderate; untrusted data reaching exec/path/egress without validation is High-to-Critical.
