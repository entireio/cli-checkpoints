### KNOWN BUG skip added (C3)
`TestGitRefsClone_UnreachableRemoteMissingRefSurfacesRealError` skips against live buggy behavior. Evidence: with a git-refs clone whose per-checkpoint ref is absent locally and whose remote is unreachable, `entire explain --checkpoint &lt;id&gt;` prints `checkpoint not found: &lt;id&gt;` instead of a real fetch error. Root cause is at the explain command layer, `cmd/entire/cli/explain_export.go:216-227`: the git-refs prefix-match remote fallback calls `FetchCheckpointRef`, and on `fetchErr != nil` falls through to `return nil, lookup` — discarding the error, yielding zero matches, which surfaces as `ErrCheckpointNotFound` at `explain.go:634`. The store layer (`refs_store.go`) correctly preserves the real error (that was the 7bbdad09c fix), but this command-layer fallback re-masks it. Per instructions I did **not** touch production code; the test self-heals (skips while masked, asserts once fixed).
